Raw data

Edit any box, or use Add and Remove. Values are whole-number percentages from 0 to 100. Press Enter to move to the next box (on the last box it adds a new one), and press Backspace in an empty box to delete it. Everything below updates automatically.

Stem and leaf diagram

One shared stem for both classes. Class A’s leaves run to the left of the stem and Class B’s to the right. Press Next to watch each value fly into place.

Hover over a leaf to see the exact value behind it.

Central tendency

Mean, median and mode for each class. Values show to 2 decimal places, but sums use exact fractions, so adding the rounded figures by hand can differ by 0.01.

Mean

The total of all values divided by how many values there are.

Median

The middle value once the data is in order. With an even number of values, it is the average of the two middle ones.

Mode

The value that appears most often.

Spread

How far the marks are spread out in each class.

Range

Highest value minus lowest value.

Interquartile range (IQR)

The spread of the middle 50% of the data: Q3 minus Q1. Quartiles come from splitting the ordered data into a lower and an upper half, leaving out the median when there is an odd number of values.

Standard deviation

The typical distance of a value from the mean.
